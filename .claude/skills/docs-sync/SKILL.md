name: docs-sync
description: Find and update the fuse docs pages a code change makes stale (docs/content/**, openapi, cli reference, sdk reference, fusefile concept page), then lint the docs. Use when a PR changes user-visible behavior, flags, fields, status codes or defaults, or when asked to "update the docs", "check docs drift" or "what docs does this touch".
---

The docs drift audit found 121 verified defects, including hand-faked transcripts and pages claiming behavior the code doesn't have. Treat every user-visible change as a docs change until proven otherwise.

## map: code change -> docs to check

| change in | check |
|---|---|
| `internal/api/*` (fields, endpoints, status codes) | `internal/api/openapi.yaml`, `docs/content/reference/api/`, the sdk reference pages for that area |
| `internal/api/errors.go` | `docs/content/reference/{go,typescript,python}/errors.mdx`, the api reference error table |
| `cli/*_cmd.go` (flags, output, exit codes) | `docs/content/reference/cli/`, every guide that shows that command |
| `internal/fusefile/`, `schema/fusefile-v1.json` | `docs/content/docs/concepts/fusefile.mdx` (field table), `docs/fusefiles/` examples (`docs_example_test.go` parses them) |
| `sdks/*` | `docs/content/reference/{go,typescript,python}/<area>.mdx` (there are no rust pages) |
| `host-agent/`, `ops/` (install, deps, systemd) | `docs/content/docs/cloud/` host-setup pages, `docs/runbooks/` |
| egress, hitl, desktop, migrate, fork | the matching guide in `docs/content/docs/guides/` |

Find the rest with grep: grep the old flag, field, error code or default value across `docs/` and the repo `README.md`.

```bash
git diff origin/main...HEAD --stat
grep -rn "<old-name-or-value>" docs/content docs/fusefiles README.md
```

## rules

- **Never invent output.** A transcript, response body or CLI output block either comes from a real run (local appliance or phantom) or is built from the code's actual struct/format string. Don't paraphrase what it "probably prints".
- **Behavior claims must match the code path.** For a sentence like "returns 409", "nothing errors" or "is free", find the line in the code that makes it true. Live-snapshot forking was documented as working in all four sdk pages while it 500'd (#221).
- Stale workaround callouts go away when their fix lands (for example, the fc-agent NUL-corruption sync callouts).
- `CHANGELOG.md` is generated by release-please. Don't hand-edit it. The /changelog page reads GitHub release bodies.
- Keep doc edits in the same PR as the code.

## verify

```bash
cd docs && bun install && bun run lint && bun run build
go test ./internal/fusefile/ -run 'Docs|Schema'
```

CI doesn't build the docs. Cloudflare Workers Builds deploys `docs/` on every push to main, so a broken build fails the deploy after merge. Run the build locally.

Report the pages you changed and the ones you checked and left alone, so the PR body can say "Docs:" with a concrete list.
